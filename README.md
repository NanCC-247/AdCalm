# AdCalm

**少点广告，多点清静。**

## 核心功能

| 功能 | 能做什么 |
|---|---|
| **辅助跳过与关闭** | 结合节点与离线 OCR 识别候选；广告专用文案，或通用关闭文案加同层明确广告标签，才进入自动操作判定。 |
| **范围可选** | 自行选择处理应用，支持搜索、筛选、批量选择和本机推荐。 |
| **误跳辅助** | 单独确认开启后，符合条件时尝试回退、返回原应用；强停另需确认及可用通道。默认关闭。 |
| **隔离恢复** | 单独确认开启后，将标准下载目录中符合条件的可疑安装包移入隔离区；保留至用户恢复或逐项确认永久删除，不定时自动删除。默认关闭。 |
| **手动清理** | 借助 Shizuku 扫描候选安装包，由用户审核并确认删除；手动删除不可恢复。 |
| **状态与诊断** | 查看服务状态、操作统计与能力自检；诊断默认关闭，日志默认导出脱敏摘要。 |

仅有位置证据不会触发点击；输入法显示时暂停点击。纯观察的识别流程只记录结果，不执行自动点击、回退、强停或新增文件隔离。暂停或纯观察后，下载通知处置也受开关门禁控制。

## 开始使用

从 [v0.1.1-beta.1 Release](https://github.com/NanCC-247/AdCalm/releases/tag/v0.1.1-beta.1) 的 **Assets** 下载 `AdCalm-v0.1.1-beta.1-arm64.apk`，按同页 `SHA256SUMS.txt` 核对文件，签名证书指纹见 `SIGNING-CERT-SHA256.txt`。正式签名不表示已达到稳定版验证程度。GitHub 的 Source code 压缩包是源码；[开发指南](docs/guides/开发指南.md)另列自行构建与 CI 测试包。

安装后：

1. 按引导开启无障碍服务。
2. 在应用管理中先选择少量需要处理的应用，在默认纯观察模式下查看行为。
3. 了解[安全使用说明](docs/guides/安全使用说明.md)后，再主动开启自动模式。增强回退、强停和下载隔离分别按需确认。

首次升级到此版本也会恢复纯观察并关闭增强操作，需要的功能请重新确认开启。

基础跳过无需 root 或 Shizuku，也不占用 VPN 连接。Shizuku 为可选增强组件，通过外部浏览器前往[官方页面](https://shizuku.rikka.app/download/)获取。

## 兼容与限制

- 支持 **Android 8.0+**；截图 OCR 需要 **Android 11+**。
- 默认构建适用于 **ARM64** 手机，其他架构需调整构建配置。
- 效果受应用界面、系统版本和后台限制影响，无法保证处理所有广告或完全避免误判。
- 无文字、无可靠节点信息的关闭按钮可能无法识别。
- 本版本收紧广告证据要求，部分旧版会点击的通用“跳过/关闭”按钮会被忽略，覆盖范围可能下降。
- OCR 路径当前只接受完整的广告专用关闭文案，例如“跳过广告”；单独“关闭”或“跳过”不会触发 OCR 自动点击。
- 操作统计记录已发起的点击，不代表每次广告都已成功关闭。
- 当前版本是 Beta，尚未形成跨设备成功率或耗电评测；欢迎提供可复现的兼容性和误点反馈。

## 隐私与权限

核心识别在本机完成。应用不内置 Shizuku 镜像下载或安装器；打开官方页面后，下载与安装由浏览器及系统处理。

新日志默认保存应用包名、判定和数值摘要。完整诊断需要明确开启，只记录所选应用的节点树和截图，原始内容留在本机；分享使用脱敏摘要并将包名替换为应用代号，仍请检查导出内容。数据范围、留存与删除方式见[隐私说明](docs/privacy.md)。
