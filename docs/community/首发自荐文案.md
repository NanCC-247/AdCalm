## V2EX 草稿

**标题：** [自荐] AdCalm：Android 本机识别的广告跳过辅助工具，邀请首批 Beta 测试

大家好，我是 AdCalm 的开发者 NanCC-247。做了一个薄荷风格的 Android 工具：在你选择的应用里，用无障碍节点和离线 OCR 识别界面已有的“跳过/关闭”按钮，再尝试辅助点击。

这次提供 v0.1.1-beta.1 正式签名 Release APK，想邀请约 10–20 位首批测试者，优先帮忙验证不同系统上的权限流程、漏识别和误点。

- Android 8.0+、ARM64；截图 OCR 需要 Android 11+。
- 基础操作无需 root 或 Shizuku，也不占用 VPN 连接。
- 新安装默认纯观察，先选择应用、查看行为，再主动开启自动模式。
- 增强回退、强停和下载隔离默认关闭，分别确认后才启用。
- 核心识别在本机完成，诊断默认关闭，日志默认分享脱敏摘要。

现在仍是 Beta。关闭按钮没有可靠文字或节点时可能识别不到；系统后台限制也会影响运行。尚未做跨设备成功率或耗电评测，点击统计只表示发起动作。

本版本收紧广告证据要求，部分通用关闭按钮会被忽略，覆盖范围可能比旧版小。隔离文件保留至用户恢复或逐项确认删除，不按时间自动清理。

源码：[NanCC-247/AdCalm](https://github.com/NanCC-247/AdCalm)（GPL-3.0）

反馈：[GitHub 问题模板](https://github.com/NanCC-247/AdCalm/issues/new/choose)

欢迎反馈“机型/系统 + AdCalm 版本 + 复现步骤 + 当时模式和增强开关”。没有日志也可以提交；请不要上传设备序列号、未打码的应用首页、原始诊断或私人截图。遇到误点先暂停或切回纯观察。

## 酷安草稿

**标题：** 开发者自荐｜AdCalm Beta，按应用选择的广告跳过辅助工具

我是 AdCalm 的开发者 NanCC-247，这次开放 v0.1.1-beta.1 测试，提供正式签名的 ARM64 APK。

它在你选择的应用里，尝试识别并点击已有的跳过或关闭按钮，用到无障碍节点和离线 OCR。基础操作无需 root，也不占用 VPN。

首次安装默认先观察，由你开启自动操作；回退、强停和下载隔离默认关闭，按需分别确认。诊断默认关闭，反馈可用脱敏摘要。

支持 Android 8.0+；截图 OCR 需要 Android 11+。当前可能漏识别、误判或被系统后台限制影响，希望先找到约 10–20 位愿意给复现步骤的测试者。

当前版本收紧广告证据要求，部分通用关闭按钮会被忽略；没有全平台覆盖或耗电评测结论。

下载与校验：[GitHub Release](https://github.com/NanCC-247/AdCalm/releases/tag/v0.1.1-beta.1)

源码与说明：[AdCalm](https://github.com/NanCC-247/AdCalm)

反馈：[问题模板](https://github.com/NanCC-247/AdCalm/issues/new/choose)。提供版本、机型/系统、模式和步骤即可，日志可选。公开素材中的第三方应用名称、图标、广告和首页应已打码，不能据此推断具体平台的适配或效果。
