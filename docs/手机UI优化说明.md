# AdCalm 手机 UI 优化说明

更新日期：2026-10-04。

按照用户提供的 AdCalm 参考图，原生 Android 页面统一为薄荷绿、浅色背景、圆角卡片和简洁图标。首页、应用、设置使用一致的底部导航，权限、日志和隔离区延续同一套视觉样式。

| 页面 | 本次完成的内容 |
| --- | --- |
| 首页 | 盾牌插画、自动／观察模式、真实应用数量、权限状态、管理应用与隔离区入口；未就绪状态显示实际缺失条件。 |
| 应用管理 | 搜索名称或包名、全部／已选筛选、当前范围全选／反选／清空、隐藏应用选项、自动保存选择及空结果反馈。键盘弹出后保留搜索、数量和列表空间。 |
| 设置 | 自动强停、自动隔离、OCR 和诊断开关，以及权限、日志、Shizuku 入口。 |
| 权限配置 | 两项必需与四项可选步骤，显示真实进度；详细说明可以展开，原有系统限制说明保留。 |
| Shizuku | 保留安装、激活、授权、状态显示和通道自检流程。 |
| 观察日志 | 显示实际文件数量及占用空间，支持导出分享和确认后清空；空状态禁用无效操作。 |
| 隔离区 | 显示文件信息、原始路径及保留状态，保留恢复和删除确认；无文件时显示空状态。 |

首页数据读取真实设置与权限状态，没有使用参考图中的固定数量。应用筛选不会丢失其他已选项目；切换自动模式、清空日志、删除隔离文件等确认流程保留。

应用图标使用用户提供的原图，原图留存在 [icon-source.png](artwork/icon-source.png)。已替换各密度启动图标、适配图标和首页品牌图；打包过程没有重新绘制原图。图标预览见 [launcher-masks.png](artwork/launcher-previews/launcher-masks.png)。

## 验证结果

编译成功，130 项单元测试通过；Android Lint **0 error / 148 warning**，全部是非阻断的
（主要是界面文案没走 `strings.xml`、依赖版本偏旧这类）。

24 项界面检查全部通过，覆盖导航、选择保存、权限展示、日志操作、模式切换等；
另有 3 项小屏及大字体检查通过（360 dp 宽、字体缩放 1.25）。检查记录属于本地设计评审
产物，没有随仓库分发。

⚠ **本次没有在真机上执行 Shizuku 安装授权，也没有验证各厂商系统的权限申请流程。**
这两块仍然只有模拟器结论。
