# AdCalm 界面设计说明

更新日期：2026-10-06。描述当前公开版本的设计方向与页面结构；详细行为以[使用指南](../guides/使用指南.md)为准。

## 视觉方向

采用薄荷绿、近白背景、深青文字与圆角卡片，围绕“简约、放松、减少打扰”组织界面。盾牌插画和轻微动态作为视觉点缀，主要操作保持清楚可见。

底部导航统一为首页、应用和设置。权限、日志、能力自检及隔离区延续同一套配色和卡片样式。

## 页面结构

| 页面 | 重点 |
|---|---|
| 首页 | 识别模式、实际服务状态、应用数量、操作统计、最近扫描时间与主要功能入口。 |
| 应用管理 | 按名称或包名搜索、全部/已选筛选、批量操作与自动保存；键盘出现时保留列表空间。 |
| 设置 | 行为选项、纯观察、OCR、诊断、增强通道与能力自检。 |
| 两步开启 | 引导开启无障碍并选择应用，其他增强权限按需配置。 |
| 权限配置 | 显示实际状态、用途与当前可用能力。 |
| 观察日志 | 查看记录、导出与清空，并提供空状态。 |
| 隔离区 | 展示文件信息、路径与保留状态，支持恢复和确认删除。 |
| 手动清理 | 展示候选安装包，核对后确认永久删除。 |

显示数量来自运行时数据，宣传图中的示意不能作为所有设备的固定状态。模式切换与功能入口可能随版本调整。

开发中已检查导航、应用选择、权限展示、日志与隔离区交互，并进行小屏及大字体检查。已有截图和测试记录对应具体构建与测试环境，不代表所有 ROM 均已验证。

当前构建与测试方式见[开发指南](../guides/开发指南.md)，无需从历史界面改版记录推断最新测试数量。
