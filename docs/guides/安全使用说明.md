# AdCalm 安全使用说明

适用于 v0.1.1-beta.1。AdCalm 在用户选择的应用中尝试操作界面已有的跳过或关闭按钮；按钮识别、自动回退与文件处理均可能受实际页面和系统影响。

## 逐步启用

新安装默认纯观察，首次升级到本版本也恢复纯观察并关闭增强操作。先选少量应用，查看状态和记录，了解动作后再主动开启自动模式。基础操作和增强回退、强停、下载处置分别控制。

增强开关开启时显示用途与确认提示。强停可能中断未保存任务，返回原应用可能改变当前页面，下载隔离可能移动正常安装包。权限授权用于提供能力，不能替代对具体动作的选择。

## 随时停止

发现误点、误回退或下载异常时，先在首页切回纯观察或暂停保护，并取消相关应用的选择。可在系统设置关闭 AdCalm 无障碍服务；无障碍绑定恢复需单独关闭，必要时撤销 Shizuku 授权。

暂停或纯观察后，下载通知处置也受门禁控制。暂停不会撤销已经发出的点击、文件移动或永久删除。已有隔离文件保持隔离，直到用户恢复或逐项确认永久删除，不按时间自动清理。手动清理的永久删除不进入隔离区。

## 识别与文件边界

单凭位置不触发点击；输入法显示时暂停点击，界面变化后复核识别结果。这些措施用于减少误操作，不能证明所有场景均无误判。

本版本要求广告专用文案，或通用关闭文案与同层明确广告标签，再进入自动动作判定。因此，部分旧版会点击的按钮会被忽略，覆盖范围可能下降。

应用没有保证处理全部广告，也没有跨设备零耗电、成功率或全覆盖结论。操作计数只表示发起动作，不能当作广告成功关闭数量。文件扫描结果是候选，删除前必须核对正常下载、待安装文件及需要保留的数据。

涉及账号登录、支付、聊天或重要文件时，先停用自动处理；诊断只记录所选应用，但其完整界面仍可能包含私人信息，排查和公开分享方法见[隐私说明](../privacy.md)。

## 使用与维护范围

仅在有权操作的设备与应用范围内使用，结合实际动作、服务条款和适用法律判断场景。默认规则不包含针对特定平台的批量适配清单，贡献识别变化时需提供复现依据和正常页面负样本。
