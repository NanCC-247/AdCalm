# AdCalm 使用指南

适用于 v0.1.0。安装来源与附件以 [Releases](https://github.com/NanCC-247/AdCalm/releases) 为准；当前 Release 仅提供源码，构建方法见[开发指南](开发指南.md)。仓库 [Actions](https://github.com/NanCC-247/AdCalm/actions/workflows/ci.yml) 的成功运行可提供临时 Debug 包，下载需登录 GitHub；是否有可用附件以对应运行为准。

## 两步开启

1. 打开 AdCalm，按“两步开启”引导前往系统设置，启用本应用的无障碍服务。
2. 回到应用管理，选择需要处理的应用。选择会自动保存，支持搜索、已选筛选和批量操作。

部分系统会限制侧载应用启用无障碍；如出现“受限设置”，按系统提示在应用信息页允许相关设置。入口随系统版本与厂商变化。

基础跳过无需 root，也无需 Shizuku。本机推荐选择使用本地记录或使用情况作为参考，推荐结果需要确认，不代表每个应用都已确认包含广告。

## 按需配置增强功能

| 能力或权限 | 用途 |
|---|---|
| 无障碍服务 | 读取页面节点并尝试点击跳过或关闭按钮。 |
| 使用情况访问 | 辅助应用使用记录、保护名单与误跳判定。 |
| 通知访问 | 在相关条件下尝试取消下载通知中的任务。 |
| 文件访问 | 监控标准下载目录、隔离符合条件的安装包并提供恢复。 |
| Shizuku | 增强强停、返回原应用、手动扫描清理及无障碍绑定恢复。 |

增强权限未配置时，部分能力会降级或不可用；以应用中的状态和能力自检结果为准。Shizuku 的启动方式因系统版本而异，请参阅[官方项目](https://github.com/RikkaApps/Shizuku)。

自动恢复无障碍绑定依赖可用的 Shizuku 通道。它用于恢复已有配置，不等于保证后台服务永远运行。

## 自动模式与纯观察

自动模式会在判定条件满足时尝试执行相应操作。应用范围、输入法防护和点击冷却用于减少不必要操作，效果仍受实际页面影响。

纯观察用于排查漏识别或误判：识别流程只记录结果，不执行自动点击、回退、强停或新增文件隔离。纯观察与诊断是不同设置；诊断会记录更多信息，需要单独开启。

**开启纯观察不会延长已隔离文件的保存期限**，原有隔离文件仍按到期规则清理。切换前已触发的下载通知处置可能在原有时间窗内短暂延续。

## 下载隔离与手动清理

这两项功能的恢复能力不同：

| 操作 | 处理方式 | 是否可恢复 |
|---|---|---|
| 标准下载目录隔离 | 符合条件的可疑安装包移入隔离区，默认保留 24 小时，到期后清理。 | 保留期限内可从隔离区恢复；手动删除或到期清理后不可恢复。 |
| 手动安装包清理 | 扫描部分应用目录与下载目录中的候选安装包，由用户核对后确认删除；需要 Shizuku。 | 永久删除，不进入隔离区。 |

扫描结果是候选文件，不等于已证实为广告下载或无用文件。删除前核对所属应用、路径与大小，正在下载或安装的正常文件应保留。

## 状态与能力自检

首页提供服务状态、操作统计与最近扫描时间。操作统计记录已发起的点击，不能据此计算真实广告关闭率。

在“设置 → 能力自检”中检查无障碍、前台窗口、截图、OCR、手势及强停通道。权限已授权与通道实际可用是两件事；未知或失败结果应结合页面给出的原因排查。

## 常见问题

**广告没有被跳过**

依次检查：应用是否已选、无障碍服务是否实际运行、当前是否为纯观察、能力自检是否通过。无文字、缺可靠节点的关闭按钮可能无法识别；Android 8–10 没有截图 OCR 兜底。

**运行一段时间后失效**

检查无障碍实际状态、厂商后台限制及相关增强通道。不同 ROM 的自启动、后台管理与省电设置不同，不承诺统一保活结果。

**出现误点或误回退**

先暂停相关处理或取消该应用的选择，记录场景与复现步骤。必要时短时使用纯观察和诊断采样，再通过 [Issues](https://github.com/NanCC-247/AdCalm/issues/new/choose) 反馈。

为避免重复点击，建议同一时间只使用一个会自动操作广告界面的工具。

## 隐私与数据

核心识别在本机完成，不通过服务器处理界面内容。主动下载 Shizuku 会联网，可能使用第三方镜像；安装仍需系统确认。

日志可能包含应用名称、候选文字与操作记录；诊断还可能包含完整节点树和截图。当前日志轮转保留最近两份，截图保留最近 40 张。

“清空日志”与截图、导出副本是不同数据范围，不能将其理解为删除全部诊断资料。公开分享前检查并遮盖私人内容；用户另存的导出文件需自行管理。

## 使用边界

支持 Android 8.0+，默认构建为 ARM64；截图 OCR 需要 Android 11+。识别、回退和后台运行都受页面与系统影响，无法保证处理所有广告或完全避免误判。请在有权操作的设备上使用。
